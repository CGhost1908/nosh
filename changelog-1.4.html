Nosh v1.4.0 Patch Notes

Version 1.4.0 transforms Nosh from a fast code scratchpad into a complete local-first developer workstation — introducing a built-in YouTube & PiP player in place of Spotify, an interactive 60fps Knowledge Graph, hierarchical folders, KaTeX math rendering, a fuzzy Command Palette, and studio-grade PDF/Markdown exports.

Built-in YouTube Companion & Floating PiP (Replaces Spotify)

Seamless background audio & video without switching windows
  • Spotify Replaced with Native YouTube Player: Removed the old Spotify API controller in favor of a zero-clutter, embedded YouTube companion widget right inside the left sidebar.
  • Floating Picture-in-Picture (PiP) Window: Pop out any study stream, tutorial, or Lofi radio into a frameless, always-on-top mini window that stays visible across your desktop.
  • Custom Transport & Playlist Support: Paste any YouTube video or playlist URL, scrub timeline progress, adjust volume, and save your favorite study streams with zero YouTube UI chrome or overlays.

Interactive Knowledge Graph & Wiki-Links

Connect notes together and explore your engineering vault visually
  • 60fps Force-Directed Knowledge Graph (Ctrl+G): Visualizes your entire note vault on an interactive HTML5 Canvas with spring attraction, node repulsion, cursor-centered zoom, node dragging, and connected cluster highlighting.
  • Bidirectional [[Wiki-Links]]: Link between notes using [[Note Title]] syntax or the Insert Link modal. Clicking an internal link jumps directly to that note or creates it on the fly.
  • Live Backlinks Popover: The editor status bar automatically counts incoming references to your active note and lets you jump to any referencing note with one click.

Sidebar Folders, Pinning & Full-Text Search

Keep hundreds of technical notes structured and instantly searchable
  • Color-Coded Sidebar Folders: Create custom folders, assign accent colors, and organize notes via drag-and-drop or the right-click context menu.
  • Note Pinning & #Hashtag Taxonomy: Pin high-priority notes to the top of the sidebar and filter your workspace with auto-extracted #tag chips.
  • Full-Text Content Search with Snippets: Sidebar search now scans inside note bodies and code blocks in real time, displaying highlighted match excerpts below each result.
  • Command Palette (Ctrl+K / Ctrl+P) & Templates: Fuzzy-search notes or run any editor command from the keyboard, and scaffold new notes from 5 built-in engineering templates (System RFC, Bug Postmortem, Meeting Notes, Daily Log, Algorithm).

KaTeX Math, Code Blocks & Distraction-Free Zen Mode

Richer technical writing and faster code editing
  • KaTeX Mathematical Formulas: Write inline ($E = mc^2$) and block ($$\sum_{i=1}^n x_i$$) LaTeX equations with instant live rendering and click-to-edit support.
  • Live Language Switcher & Line Wrap: Click the language badge on any code block to switch syntax highlighting mode on the fly, or toggle per-block line wrapping.
  • Interactive Checklists, Outline Drawer & Find/Replace: Track tasks with persistent checkboxes, navigate headings via the slide-out Document Outline (Ctrl+Shift+O), and run in-note Find & Replace (Ctrl+H).
  • Zen Focus Mode (Ctrl+Shift+F / F11): Collapse the sidebar, toolbar, and status bar into a clean, centered reading & writing canvas.

Studio PDF Export, Cloud Publishing & Workspace Themes

Share clean documents anywhere and customize your environment
  • Isolated Vector PDF & Markdown Export: Export crisp A4 PDFs with GitHub Light syntax highlighting and KaTeX math, or export/import standard Markdown (.md) files via drag-and-drop.
  • Cloud Web Publishing & Auto Media Hosting: Publish notes to shareable web links via Supabase Cloud with automatic Catbox image/video hosting and live KaTeX/code rendering.
  • 4 Workspace Themes & Trash Recovery Manager: Choose between Obsidian Dark, OLED Pure Black, Nord Slate, and Tokyo Night, and safely restore deleted notes from the built-in Trash manager.
  • 90% Smaller .nsh Files & Local Media Assets: Clean HTML serialization strips transient editor DOM nodes on save, while pasted images are stored in Saves/assets/ for instant loading.
