# 📝 Nosh - The Notepad for Developers & Students (Official Landing Page)

Welcome to the official web showcase and landing page repository for **Nosh**, a specialized, distraction-free note-taking and snippet management app crafted specifically for software developers and computer science students.

---

## 🌟 Highlights & Features Promoted

- 💻 **10+ Syntax Highlighted Languages**: Embedded code snippet editor with dedicated language modes and autocomplete.
- 🎵 **Spotify Music Player Integration**: Directly control playback, track progress, and volume inside your workspace without context switching.
- ☁️ **Cloud Synchronization**: Google Drive backup integration for seamless cross-device synchronization and note preservation.
- 📱 **Multi-Platform Vision**: Desktop-first experience with planned mobile companions.
- 🛡️ **Privacy-First Design**: Full disclosure with dedicated Terms of Service and Privacy Policy pages.

---

## 🛠️ Tech Stack

- **Markup & Styling**: Semantic HTML5, Custom CSS3 (Modern Flexbox/Grid, smooth scrolling, responsive viewports)
- **Typography**: Google Fonts (Jersey 10, modern sans-serif)
- **Icons**: Iconify Web Components
- **Hosting**: GitHub Pages ready (static site deployment)

## 🚀 Live Preview & Local Development

### Run Locally

Simply clone and open `index.html` in any browser, or use Python's built-in HTTP server:

```bash
git clone https://github.com/CGhost1908/nosh.git
cd nosh
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.
